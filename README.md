# Reports and presentations

Slides, poster, final report and project-management docs for the ADLM project
[adlm-multimodal-uncertainty](https://github.com/ADLM-Multimodal-Uncertainty/adlm-multimodal-uncertainty).
Figures generally come from the [eda](https://github.com/ADLM-Multimodal-Uncertainty/eda) repo
or from `results/` in the main repo.

## Rules

- This repo is public. Do not commit patient data, the course's own slides, or paper PDFs.
- Commit the exported PDF of every slide deck we present, so each presentation has a fixed version.
